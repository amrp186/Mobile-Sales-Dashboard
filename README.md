# 📱 Mobile Sales Performance Dashboard

## 📊 Project Overview

The **Mobile Sales Performance Dashboard** is an interactive Power BI analytics project designed to provide a clear and actionable view of mobile sales performance, product demand, customer behavior, and payment trends.

The dashboard transforms transactional mobile sales data into meaningful business insights, helping stakeholders quickly understand **revenue performance, sales volume, brand contribution, customer purchasing patterns, and top-performing mobile models**.

The project focuses on building a clean, business-oriented dashboard that enables users to explore sales performance dynamically using filters such as **Month** and **City**.

---

## 🎯 Business Objectives

- Monitor overall **revenue and unit sales performance**
- Compare **revenue contribution across mobile brands**
- Identify brands generating the highest sales volume
- Analyze **daily revenue trends** and sales fluctuations
- Understand customer **payment method preferences**
- Identify the **top-performing mobile models by revenue**
- Track **Average Order Value (AOV)** as a key sales metric
- Enable interactive analysis by **Month and City**
